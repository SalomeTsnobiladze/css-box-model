CSS Box Model როგორ მუშაობს ზომები?

მოდი, მარტივად ვნახოთ, როგორ აწყობს ბრაუზერი ვებგვერდის ელემენტებს.

Box Model-ის 4 შრე (როგორც საჩუქრის ყუთი )

წარმოიდგინე, რომ თითოეული ელემენტი არის საჩუქრის ყუთი, რომელიც შედგება 4 ფენისგან:

  • Content (შიგთავსი): თავად ტექსტი ან სურათი, რომელიც ყუთის შიგნით დევს.
  • Padding (შიდა სივრცე): ჰაეროვანი ადგილი შიგთავსსა და ყუთის კედლებს შორის.
  • Border (ჩარჩო): თავად ყუთის მყარი კედელი / გარე საზღვარი.
  • Margin (გარე მანძილი): თავისუფალი სივრცე ამ ყუთსა და სხვა მეზობელ ყუთებს შორის.

ოქროს წესი (Best Practice)

იმისათვის, რომ თავიდან აირიდო გაფუჭებული განლაგება და ზომების მუდმივი თვლა, პროექტი ყოველთვის დაიწყე ამ CSS წესით:

*, *::before, *::after {
        box-sizing: border-box;
    }

დასკვნა: ეს წესი უზრუნველყოფს, რომ ყველა ელემენტმა ზუსტად შეინარჩუნოს შენ მიერ მითითებული სიგანე და სიმაღლე (`width` / `height`), მიუხედავად იმისა, თუ რამდენ `padding`-ს ან `border`-ს დაამატებ.
